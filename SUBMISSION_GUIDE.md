## What stays in GitHub

The repository holds the Python source, SQL schema and queries, sample inputs, cleaned dimensions, notebook, Streamlit dashboard, charts and KPI outputs, validation files, Power BI DAX, Excel/Power BI guides and dataset documentation.

## Data note

The input records were generated for this academic project using `scripts/generate_demo_data.py` and a fixed random seed. They are synthetic, not real patient data and not an official Synthea sample. The reported counts and rates describe only this generated sample.

A Power BI model guide and DAX measures are included. A native `.pbix` file is not included because it must be created and saved from Power BI Desktop.
